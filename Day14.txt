What is OS?
OS is a software which is used to interact with the machine (laptop/mobile/desktop/server...)
OS acts as a mediator b/w user and the machine
OS is mandatory to use any device/machine
OS provides an environment to run the applications

Types of OS;
Windows, Mac, Android, Linux, Ubuntu, RedHat...

Windows Vs Linux;
Windows is a single user based OS
Linux is a multi-user based OS

Windows is premium 
Linux is free and Open Source

Windows doesn't have better security features
Linux is fully secure

Windows is GUI based
Linux is CLI (Command Line Interface) based

Windows is recommended for personal use
Linux is for professional use

Windows is developed and owned by Microsoft
Linux is developed by Linus Torvalds

Note: all Linux commands are case sensitive

Linux distributions/flavours;
A Linux distribution/flavour is an OS that is built on top of the Linux kernel
AWS - AMIs - RPM based (RedHat, CentOS, Amazon Linux) - yum
